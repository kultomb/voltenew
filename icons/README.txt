Đặt logo ứng dụng tại đây
========================

Tên file (bắt buộc):
  app_icon.ico

Vị trí:
  HBGAdBlocker/icons/app_icon.ico

Gợi ý tạo file .ico:
  - Kích thước khuyến nghị: 256×256 (nên gồm thêm 16, 32, 48 trong cùng file .ico)
  - Nền trong suốt nếu có thể
  - Xuất từ PNG bằng: https://icoconvert.com hoặc GIMP / Photoshop

Sau khi thêm file:
  - Chạy app Python: icon thanh tiêu đề + logo sidebar
  - Build EXE (build_exe.bat): icon file .exe + cửa sổ app

Không có app_icon.ico → app dùng biểu tượng 🛡 mặc định trong sidebar.
